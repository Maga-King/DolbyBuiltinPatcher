# 使用与数据边界

## ROM 内置

输入应为完整解包目录，含 system、system_ext、vendor、odm、product 及 config 打包元数据。
工具支持实际布局识别，但不解包 OTA/payload/super，也不直接生成或刷入分区镜像。

“一键修改 ROM”会先备份，再原位修改选中的解包目录。完成后使用原打包工具重建报告中涉及的分区。
ZIP 不能保存 Android SELinux xattr，必须使用更新后的 fs_config/file_contexts 打包；仅复制文件不够。

构建目录中的 `original_files` 是回退备份，`records` 和报告用于追溯，**不要放进 ROM**。
config 是打包器元数据，不是 Android 的 `/config` 分区。

默认记录位置为 `%LOCALAPPDATA%\DolbyBuiltinPatcher\history`。
ADB 模式的手机备份位于所选 ROM 父目录的 `.dolby-patcher-backups`。
回退会核对后续改动；强制关机、SIGKILL 或存储耗尽不保证自动恢复。
请勿在事务进行时同时打包、改同一目录或切换 ROM。

## 模块生成

模块生成只读输入，保存 ZIP，不安装、不重启。输出路径不要放进输入 ROM。
多设备连接时必须选择目标设备；ADB 实时读取只允许检查/生成模块，不允许写回当前运行分区。
实时可见系统可能包含其他模块挂载；不要将已启用杜比的系统当作纯净输入。

安装和启用交给 KSU 管理器。安装器允许更新本模块自有早期 metadata；不再按设备指纹、SDK、
架构或原文件哈希拒装。必要工具、路径和实际操作错误仍会导致失败。切换 ROM 或 OTA 后仍建议重新生成。

## SELinux 和兼容性

工具先编译 ROM 原始普通/debug 基线，再合入必需规则、上游规则与按目标声明筛选的扩展规则。
原基线不能编译时停止；不删除原厂规则来凑通过，不设置全局 permissive。
编译使用 `secilc -N`，不会依据 neverallow 断言裁剪规则；这不等于权限最小化或所有运行风险都已排除。

上述编译流程仅用于原生内置。模块直接导出必需规则、Lunaris 上游、完整杜比扩展库和原厂普通策略中
显式相关的顶层 allow 为 sepolicy.rule，不调用 secilc、不挂入整份预编译策略。
缺少对应类型/类/权限的扩展保留并记录；KSU/Magisk 可能拒绝部分规则，但不会预判所有开机风险。
对 Enforcing、多机型和长期稳定性仍需要实际验证。

## 解码与缓存保护的边界

解码服务去掉 oneshot 并提供接口启动映射后，init 可以在其退出后恢复服务。
这不能证明专有解码库不会再次崩溃，更不能把“服务已注册”当成“真实码流解码成功”。

开机缓存保护对模块 RC 与 KSU 聚合 RC 的完整所属段落做一次比较；不一致时限时调用 KSU 刷新。
刷新只改变下次启动的定义，不重启系统服务、不热加载当前 init。Action 仅读状态。
日志位于模块 `.runtime/initrc-cache.log`；`CACHE_REFRESHED_NEXT_BOOT_ONLY` 表示仍需重启才会应用。

如果持续出现格式错误、黑壁纸、系统卡顿或解码服务 PID 频繁变化，请停用模块并保留脱敏日志。
不要反复强杀 HWS 或通过禁用 CFI 来掩盖异常。
