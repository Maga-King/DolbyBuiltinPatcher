# 手机版 0.2.0 / 桌面 0.6.1 同步更新

2026-09-28，模块署名：科比。LunarisDolby 来源见根目录 README。

## 手机端

- 保留读取当前系统生成模块。
- 新增输入手机解包目录，只读生成模块。
- 新增原位内置 ROM：使用与电脑端相同的补丁和 SELinux 编译流程。
- 新增查询事务、回退、保留备份的缓存清理、指定 ROM 备份删除。
- 写回阶段不强杀一次性事务；未决状态阻止重复修改和清理。
- 随包构建 ARM64 secilc，无需手机安装编译环境。

## 电脑端

- 本地 ROM、ADB ROM、实时读取共用最新自挂载模块模板。
- 同步 App 同签名安装、数据目录标签修复和中文 Action 诊断。
- 修复窗口版 EXE 被 PowerShell 启动时，无效 stdout 导致的 Error 22；日志输出失败不再中断构建或掩盖原异常。
- 统一 Windows / Android 的 manifest 文件名排序，避免同一 ROM 两端挑选不同的挂载目标。
- 原生内置文件合并逻辑未改：共享传输新增可选本机 root 入口，策略编译器新增 Android 路径注入；Windows 默认路径保持。
